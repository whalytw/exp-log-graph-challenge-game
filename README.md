# 指數與對數・繪圖闖關

沿用「三角函數・繪圖闖關」的三區獨立操作方式，改為教師可選底數的指數與對數函數。左、中、右區各自開始、計時、送出、換題與結算，完成即可換下一位。

## 使用與 GitHub Pages

下載版解壓縮後，直接開啟 `index.html` 即可試玩，不需安裝套件或連網。推薦使用桌面版 Chrome 或 Edge，按「全螢幕」或 F11。

上傳 GitHub Pages 時，將解壓縮後的 `index.html`、`app.js`、`engine.js`、`style.css` 放在新儲存庫的最上層。到 Settings → Pages，將來源設為 Deploy from a branch，選擇 main 與 /(root)，儲存後等待發布。可使用儲存庫名稱 `exp-log-graph-challenge-game`。

請建立新的儲存庫，以保留原本的三角函數遊戲。這份下載包已包含所有遊戲資源，不使用外部 CDN。

## 題型與教師設定

題目採用以下模型，其中底數 a 由教師在「出題底數」勾選，指數與對數共用。選項由小到大為 1/10、1/5、1/3、1/2、2、3、5、10，預設勾選 1/3、1/2、2、3，至少需選一種：

- 指數：y = A · a^[B(x − h)] + k。
- 對數：y = A · logₐ[B(x − h)] + k，真數必須大於 0。
- 左右平移 h：−2、−1、1、2。
- 左右伸縮：內部係數 B 為 1/2 或 2，圖形的水平倍率分別為 2 或 1/2。
- 上下伸縮 A：1/2、2、3。
- 上下平移 k：−2、−1、1、2。

一星為基礎圖形，二至五星分別組合 1、2、3、4 種變化。每個星等可分別選擇指數／對數、可用變化、題數與限時。全選八種底數時共有 4,800 種參數組合，使用預設四種底數時為 2,400 種。正餘弦疊合及第六星已移除。

預設題數為 2、1、1、0、0，共 4 題；限時依序為 40、60、80、100、120 秒。每星可設定 0～20 題，限時 10～300 秒，每 10 秒一個選項。座號預設 1～30，可不填。

座標範圍固定 x：−6～10、y：−6～12，每格 1 單位，數字每 2 單位標示。只需畫出座標框中的可見曲線。教師可調整深淺色、格線顏色與粗細、座標文字大小與顏色。

題型、題數、時間、求救卡等設定從下一位學生開始生效；目前各區保留開始時的設定。顯示主題與座標樣式立即套用。設定保存在目前瀏覽器。v1.1 會自動將舊版預設題數 1、1、1、0、1 更新為新版預設 2、1、1、0、0，並加入預設四種底數；其他自訂題數會保留。需要重新套用全部預設值時，在教師設定按「恢復預設設定」後儲存。

## 兩種求救卡

一般求救卡預設第 15 秒亮起第一張，之後每 10 秒取得一張，每題最多 3 張。老師可調整首張等待、間隔與上限 0～3。未使用的卡可累積，本題使用後不補發超過上限。每題重新計算。

一般卡每次隨機揭示一個尚未使用、整數刻度間寬度恰為 1 的 x 區間，例如 2～3、−1～0。會跳過沒有可見曲線的區間。該區筆跡清除、出現煙霧並逐漸浮現答案，區域鎖定並計為正確；復原不會把該區筆跡或卡片還原。這樣不會抽到對數無定義的空白區。

有平移或伸縮的題目額外提供 **1 張基準線求救卡**。與首張一般卡同時亮起，不消耗一般卡張數。使用後顯示同底數的 y = aˣ 或 y = logₐ x 藍色點線，持續至本題結束。此卡不清除或鎖定筆跡，也不直接替目標曲線加分。基礎圖形題不提供基準卡；一般卡上限設 0 時，兩種卡均停用。

每使用任一種卡，本題分數都再乘以 0.8，最後四捨五入。例如：

| 一般卡 | 基準卡 | 分數倍率 |
| --- | --- | --- |
| 0 | 0 | 1 |
| 0 | 1 | 0.8 |
| 1 | 1 | 0.64 |
| 3 | 1 | 0.4096 |

## 評分與操作

以曲線長度分布的 96 個點檢查可見目標曲線，並檢查學生多餘筆跡，兼顧完整度與準確度。距離以標準化畫面座標計算，近乎垂直的對數分支也列入檢查。無定義區或超出座標框的目標部分不要求繪製。每題 0～100 分，2 秒後自動換題；時間到自動送出，完成顯示總分。

基準卡只提供參考：空白作答且只使用基準卡仍為 0 分。一般卡揭示區段會計為已完成，再套用所有用卡折減。

細筆、橡皮擦與復原均獨立。橡皮擦只清除學生筆跡。墨水量限制用來避免大量塗滿畫面；擦除多餘筆跡後可繼續畫。

送出後：各區代表色為學生筆跡、粉紅／紫紅為一般卡答案、藍色點線為基準曲線、橘色虛線為目標答案、灰色點線為目標漸近線。

三區採用獨立 Pointer Events 與 pointerId，接受非主要觸控，其他同學正在畫圖時仍可操作本區工具。實際多人觸控需投影連線把多個觸控點傳送給 Windows 與瀏覽器；上課前請在現場確認。

## 開發與驗證

遊戲檔案位於解壓縮後的最上層，開發測試位於 `tests/`，無需安裝依賴。

```sh
node --test tests/*.test.cjs
```

驗證包含全部題庫的變化數、對數定義域、可見曲線、求救區間、評分倍率、空白作答、三區獨立換題、基準卡單次使用、次要指標事件，以及設定從下一位學生生效。流程測試使用簡化 DOM，不代表已完成實際瀏覽器版面或大螢幕硬體驗收。
